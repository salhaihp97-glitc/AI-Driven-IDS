# ============================================================================
# QUICK START GUIDE
# ============================================================================
# 1. Copy all REQUIRED items above to the target machine
# 2. Create virtual environment:
#      python -m venv venv
#      venv\Scripts\activate        (Windows)
#      source venv/bin/activate     (Linux/Mac)
# 3. Install dependencies:
#      pip install -r requirements.txt
# 4. Configure environment:
#      copy .env.example .env
#      Edit .env with your settings (especially AI_IDS_SECRET_KEY)
# 5. Create required directories (if not present):
#      mkdir logs
#      mkdir data
#      mkdir models
# 6. Run the application:
#      streamlit run app.py        (Web UI)
#      python cli.py               (CLI interactive menu)
#
# Default login credentials (seeded automatically):
#   Username: admin
#   Password: admin
#
# IMPORTANT: For live network capture features, run as Administrator/root.
